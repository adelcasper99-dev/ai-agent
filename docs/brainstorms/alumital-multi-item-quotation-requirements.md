# متطلبات منظومة المقايسات متعددة البنود وحوكمة أزرار التيليجرام (Alumital Multi-Item Quotation Requirements)

## 1. ملخص المتطلبات ومجال العمل (Scope & Core Intent)
1. **دعم المقايسات متعددة البنود (Multi-Item Quotations):** تمكين التاجر من إملاء أي عدد من الفتحات (شبابيك، أبواب، مطابخ، واجهات) في أمر صوتي أو نصي واحد واستخراجها بدقة عبر `calculate_alumital_quotation`.
2. **التطبيق الإلزامي للحد الأدنى (Per-Unit Minimum Billable Area Floor):** تطبيق قاعدة الـ `1.00 م²` لكل وحدة يقل مقاسها عن متر مربع (مثل 70×70 = 0.49 م² تحتسب 1.00 م² محاسبياً).
3. **حظر الهلوسة الحسابية (Zero-Hallucination Guardrail):** منع الـ LLM نهائياً من كتابة جداول مالية أو حساب أرقام وفلوتات نصياً في الرد المباشر، وإلزامه باستدعاء الأداة حصراً.
4. **كروت التيليجرام التفاعلية وأزرار الحوكمة (Telegram Guardrail Buttons):**
   - إرسال كارت تيليجرام تفاعلي يحوي تفاصيل المقايسة (الأمتار الفعلية، الأمتار المحاسبية، سعر المتر، الإجمالي) مع أزرار:
     - `[✅ اعتماد وتوليد PDF والرسم]`
     - `[✏️ تعديل مقاس]`
     - `[💵 تعديل سعر / خصم]`
     - `[❌ إلغاء المسودة]`
5. **التعامل مع زر التعديل والإلغاء:** دعم التعديل السريع عبر إرسال المقاس أو السعر الجديد وتحديث المقايسة المسودة فوراً.
